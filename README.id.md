### Tentang

Saya membangun produk web dari ujung ke ujung, mengujinya sampai andal, dan merapikan data di belakangnya. Saya suka antarmuka yang jelas, pipeline yang tepercaya, dan pengujian yang menangkap masalah sebelum pengguna menemukannya.

### Tools yang saya pakai

`Python` `TypeScript` `PHP` `Laravel` `React` `Next.js` `Playwright` `Docker`

### Proyek pilihan

- **[Jogjacare](https://github.com/MasterPandaa/Jogjacare)**: aplikasi web sistem manajemen klinik dan layanan kesehatan modular berbasis Laravel.
- **[QR-Camera](https://github.com/MasterPandaa/QR-Camera)**: ekstensi browser untuk pengujian QA otomatis melalui injeksi virtual QR code pada webcam.
- **[Tokprice-Predictor](https://github.com/MasterPandaa/Tokprice-Predictor)**: aplikasi machine learning prediksi harga produk menggunakan TF-IDF dan regresi.
- **[Mimik-Plus](https://github.com/MasterPandaa/Mimik-Plus)**: ekstensi komunitas dengan dukungan penyedia AI kustom dan lokalisasi bahasa.
- **[Prompt-Engineering-Collection](https://github.com/MasterPandaa/Prompt-Engineering-Collection)**: repositori riset evaluasi SAST terhadap kualitas kode berbasis LLM dengan prompt engineering.
- **[ASSRI](https://github.com/MasterPandaa/ASSRI)**: platform otomatisasi sistem cerdas dan integrasi sumber daya.
