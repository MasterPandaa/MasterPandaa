Software engineer dan data engineer dengan spesialisasi pengembangan platform web siap produksi, integrasi kecerdasan buatan, dan keandalan sistem. ### Benchmark Machine Learning &amp; Dataset Terbuka

| Sasaran Model | Arsitektur Machine Learning | Hasil Evaluasi |
| :--- | :--- | :--- |
| Deteksi transaksi fraud | Regularized Logistic Regression | Akurasi 94%, precision 0.89, recall 0.82 |
| Sentimen ulasan pelanggan Gojek | Ekstraksi fitur TF-IDF dengan Random Forest | Akurasi 86%, skor F1 0.84 |
| Sentimen ulasan aplikasi Spotify | Bidirectional LSTM dengan learned embedding | Akurasi 89%, skor F1 0.87 |
| Rekomendasi graf film | GraphSAGE via PyTorch Geometric | Recall@10 0.31, NDCG@10 0.28 |
| Regresi estimasi harga Tokopedia | Ridge Regression dengan NLP judul produk | R² 0.78, RMSE 42.3 |
| Klasifikasi risiko preeklamsia | Random Forest multiclass classification | Akurasi 91%, recall 0.88 |

Saya mempublikasikan pipeline ekstraksi data dan dataset terbuka di [Kaggle](https://www.kaggle.com/pandaa12) yang mencakup 50.000 produk Tokopedia, 18.000 rekaman sentimen YouTube banjir Sumatra 2025, 12 koleksi ulasan Google Play, data perhotelan Yogyakarta dari Traveloka, dan metadata film TMDB. Pipeline scraping dibangun menggunakan Playwright, google-play-scraper, dan TMDB API.
